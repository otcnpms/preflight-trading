# PreFlight Trading

A standalone pre-trade methodology companion for Thinkorswim.

## Purpose

PreFlight is not a trading signal or recommendation engine. It helps a trader execute a repeatable pre-trade methodology, document the checks performed, optionally tag recognized strategy setups, and keep a structured trade record.

## V1 flow

Ticker → Core Pre-Flight → Optional Strategy Tag → Option Details → Position Plan → Final Review → Save Trade

The universal checklist is always present. Strategy setups (E1–E12) are conditional and never required merely because they exist.
